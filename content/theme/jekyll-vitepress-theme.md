# Jekyll VitePress Theme

Jekyll VitePress Theme reproduces the VitePress documentation experience in a pure Jekyll workflow.

## Features

- VitePress-style top nav, sidebar, and right-side outline
- Built-in local search modal (`/`, `Ctrl/Cmd+K`, `Cmd+K`)
- Dark, light, and auto appearance modes
- Code copy buttons, language labels, and file-title bars
- Optional GitHub star button with live count
- Jekyll-native extension hooks and YAML-based configuration
- Works as a gem-based theme for Jekyll sites
