# Lynn – A theme for hosting your links & socials online

Link-in-bio tools trap creators in sterile, proprietary ecosystems—but what if you could own your digital presence entirely? Lynn is a self-hosted Jekyll theme that delivers the functionality of tools like Linktree with the raw aesthetic of brutalist web design. No subscriptions, no branding, no algorithmic interference.

Built with uncompromising minimalism, Lynn features a responsive image carousel, custom color schemes, and beautiful typography. Every element serves a purpose: showcase your work, direct your audience, maintain complete control. It’s digital independence wrapped in bold, customizable rebellion.

## Features
* Self-hosted alternative to Linktree and similar platforms
* Responsive image carousel with smooth navigation
* Customizable color themes
* Customizable and modular design via YAML configuration
* Comprehensive documentation and setup guides
* Outstanding Lighthouse performance scores (95-99)
* Minimalistic design with tiny repository footprint
* Mobile-first design approach
