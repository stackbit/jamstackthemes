## Ready Set Walk Hugo Theme

A vibrant, configurable Hugo theme designed for teen dog walkers and pet services. A fun, fast, and fully responsive single-page Hugo theme. Perfect for teen entrepreneurs, pet sitters, and local services.

![Screenshot](https://raw.githubusercontent.com/StaticDesigns/ready-set-walk/refs/heads/main/static/screenshot-full-hero2.png)

## Features

- **Blazingly Fast**: The theme is designed for speed
- **Single-page layout**: Hero, gallery, pricing, about, and contact sections in one scrollable page
- **Tailwind CSS**: Modern, responsive styling with full customization
- **Dog gallery**: Showcase pet photos with lightbox support
- **Pricing tables**: Flexible service pricing display
- **Contact form**: Built-in form handling (Choose from - FormSubmit, Formspree, and Netlify)
- **No CMS required**: Pure static Hugo with markdown configuration
- **Mobile-first**: Perfect for teen entrepreneurs on any device

## Quick Start

Follow the instructions in the theme [README](https://github.com/StaticDesigns/ready-set-walk/blob/main/README.md) to quickly and easily install Read Set Walk in your Hugo site.
