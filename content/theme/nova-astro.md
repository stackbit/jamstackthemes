# Nova, Creative Agency Template

Nova is a responsive one-page template for creative agencies, design studios and ambitious brands. It uses Astro, Tailwind CSS and TypeScript, with content kept in JSON files for quick customization.

## Features

- English and Polish homepage content
- Selected work, services, team, testimonials, FAQ and CTA sections
- Responsive layouts for mobile, tablet and desktop
- Self-hosted fonts, optimized images, sitemap and SEO metadata
- Static output for any static hosting provider
