# A one-page Jekyll theme for freelancers

Alcor is a free, MIT-licensed one-page theme for freelancers and small studios: warm paper, ink and one vermilion accent. It runs on GitHub Pages' built-in build, with no GitHub Actions and no custom plugins.

## Features

* One page built from sections: hero, client names, services, work, process, about, testimonials, FAQ and contact
* Reorder, hide or repeat sections from one file
* Works on GitHub Pages (use as a template or with `remote_theme`)
* Light and dark mode that follows the visitor's setting, with a switch
* No jQuery, no Bootstrap, no icon font; under 1 KB of JavaScript
* Accessible: WCAG AA colour contrast in both modes, skip link, focus styles
* Contact form with no JavaScript (Web3Forms or Formspree)
* Six MIT illustrations that recolour with the theme and dark mode
* SEO tags, sitemap, social image and structured data
