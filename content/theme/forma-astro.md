# Forma, Construction and Renovation Template

Forma is a one-page Astro template for local construction and renovation businesses. Homepage content lives in simple data files, so it is quick to adapt to a real company.

## Features

- English and Polish routes
- Hero, services, example projects, process, testimonials, service area, FAQ and contact form
- Tailwind CSS v4 with design tokens generated from one theme file
- Self-hosted Instrument Sans and optimized responsive images
- MIT license
