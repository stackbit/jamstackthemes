# Hugo Mini

Hugo Mini is a lightweight theme for personal blogs and writers. Its public demo showcases the bilingual example site, with no required JavaScript framework or external asset CDN.

## Features

* Responsive reading layout and system-aware dark mode
* English and Russian navigation and example content
* Self-hosted fonts, CSS, JavaScript, and generated Open Graph images
* RSS, JSON Feed, structured metadata, and `llms.txt`
* Optional KaTeX, Mermaid diagrams, and Telegram integrations
