# EchoFolio - A Minimalist Jekyll Portfolio Theme

EchoFolio is a lightweight and high-performance Jekyll theme built to help you launch a professional portfolio in minutes. It focuses on clean typography and a seamless user experience.

## Features

* **Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
* **Modern Aesthetic:** Clean and minimalist design that puts your work front and center.
* **Easy Configuration:** Manage your social links, projects, and bio directly from the `_data` folder YML file(s).
* **SEO Friendly:** Built-in metadata and clean structure for better search engine ranking.
* **GitHub Pages Ready:** Deploy instantly using GitHub Pages with zero configuration.
