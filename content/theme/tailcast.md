# Tailcast

Dark-themed website template built with Astro 6 and Tailwind CSS 4, designed for a fictional startup.

## Features

* 8 pages - Home, About, Services, Blog, Article, Careers, Contact, 404
* SEO optimization - Sitemap, Open Graph, canonical URLs, meta descriptions
* View Transitions - Smooth page navigation with Astro Client Router
* Responsive - Mobile-first design that adapts to any screen size
* Code quality - ESLint, Prettier and CI pipeline pre-configured
