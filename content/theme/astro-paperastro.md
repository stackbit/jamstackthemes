# PaperAstro — A Minimal, Professional Astro Starter

PaperAstro is a lightweight, production‑ready starter template for Astro.  
It provides a clean foundation for blogs, portfolios, and content‑driven sites, with a focus on typography, structure, and maintainability.

## Features

- PaperCSS‑driven UI with a clean, readable aesthetic  
- Fully responsive layout  
- Blog system with tags and dynamic routing  
- About, Contact, and BlogPost templates included  
- Fabform.io integration for contact forms  
- SEO‑friendly structure  
- Minimal, brand‑consistent components  
- Easy to extend and customise
