# astro-inkstone

The Astro wiki you can write in. **astro-inkstone** is the appearance layer for Astro documentation sites, wikis and digital gardens: two-tier design tokens, content styles tuned for long reading, 25 components (heroes, callouts, tables that turn into cards on phones, code frames, a search palette, a local link graph) and a one-line Markdown pipeline preset — KaTeX, Mermaid, callouts, `[[wikilinks]]` with backlinks, chapter numbering, reading time, and a build-failing content guard.

Paired with **astro-inkbrush**, its editing engine, the site becomes a wiki you write *in*: hover a block, click ✎, edit Markdown with a live preview rendered by the site's own pipeline, and save as a git commit — with block-level revision history, comments, AI assist and an Obsidian inbox. Production builds carry zero CMS bytes.

The demo is the package's own manual, written with the package, in 18 languages, with a **Try editing** playground that runs the real editor on the static site.
