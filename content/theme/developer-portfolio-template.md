# Developer Portfolio Template

Developer Portfolio Template is a lightweight and customizable Jekyll starter for developers, researchers and students who want to publish projects, case studies and technical articles using GitHub Pages.

## Features

* Responsive portfolio and technical blog
* Built-in multilingual support
* Automatic light and dark mode
* Project, case study and article layouts
* Search powered by Pagefind
* Centralized appearance configuration
* Automatic GitHub Pages deployment
* SEO metadata, sitemap and feed
* No heavy frontend framework
* MIT licensed
