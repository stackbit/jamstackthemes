# E25DX

No need Hundreds of NPM Packages & Thousands of CSS Classes For A Modern And Modular Technical Documentation & Blog Setup

## Features

- Minimal reliance on external frameworks (No CSS, JS/npm, icon, font frameworks).
- Built for Performance.
- Zero Bloat and Secure.
- Responsive and adaptive layouts.
- Support for light and dark modes.
- Support for multiple documentation sets.
- Support for a blog.
- Implement a menu via Hugo configs.
- Customizable sidebars using Hugo data templates.
- Plug-and-play/ repeatable home page blocks using separate partials/ css/ data templates.
- Integrate a search via Pagefind.
