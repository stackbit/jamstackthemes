## Quire: a blog theme for Hugo

Quire is a free, MIT-licensed blog theme for Hugo, built with Tailwind CSS v4. It ships a prebuilt stylesheet, so it works with Hugo alone; an opt-in Tailwind build is there for your own classes.

**View demo:** [https://quire.themes.dev/](https://quire.themes.dev/)

## Features

* Featured post and a masonry archive
* Topic pages with photos
* Article layout with table of contents, author box and related posts
* Search, RSS, sitemap and Open Graph tags
* Light and dark mode
* No Node required
