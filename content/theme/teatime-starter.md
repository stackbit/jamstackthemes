# TEAtime Starter

- Tailwind CSS 4 with CSS-first configuration
- Eleventy 3 (ESM) with plugins, filters and shortcodes
- Alpine.js interactivity with CSS animation
- Nunjucks templates and Markdown content with custom attributes
- Image optimisation, SEO meta tags, dynamic sitemap.xml and robots.txt
- HTML and CSS minification out of the box
- One-click deploy to Netlify (Firebase Hosting also supported)
- AGENTS.md / CLAUDE.md guides for AI coding agents
- Custom 404 page
